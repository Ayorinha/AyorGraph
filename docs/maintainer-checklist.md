# Maintainer Checklist

Use this checklist before merging a change into `main`.

- [ ] The change has a focused scope.
- [ ] Tests cover the affected behavior.
- [ ] Documentation is updated when public behavior changes.
- [ ] CI checks are green.
- [ ] Security-sensitive changes receive appropriate review.
- [ ] The pull request explains validation performed.
- [ ] No unrelated files or generated artifacts are included.

## Release hygiene

Prefer small, reviewable pull requests and keep `main` in a releasable state.
