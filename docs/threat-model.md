# Threat Model\n\nAssets: data, credentials, model inputs and outputs, tool permissions, provenance, and availability.\n\nThreats: injection, malicious inputs, secret leakage, unauthorized actions, dependency compromise, poisoning, denial of service, and weak auditability.\n\nControls: validation, least privilege, isolated adapters, secret hygiene, audit evidence, dependency auditing, deterministic tests, and fail-closed authorization.\n
