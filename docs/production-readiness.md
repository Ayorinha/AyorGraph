# Production Readiness

## Definition of done

- [x] Source package exists and is importable
- [x] CI compiles source and tests
- [x] Ruff quality gate is present
- [x] Security boundary is documented
- [x] Architecture boundary is documented
- [x] Smoke tests are explicit
- [ ] Domain-specific benchmark/evaluation evidence evolves with the project
- [ ] Release artifacts are produced only after CI validation

The unchecked items are deliberate project evolution tracks, not hidden failures.
